## Résumé generation
- `resume.pdf` is regenerated by `scratchpad/build_resume.py`, which reads
  `scratchpad/original_resume.pdf`, keeps page 1 byte-identical, and re-typesets
  the lower portion of page 2 (adds the eDNAtlas project + an Awards & Honors
  section) using full system DejaVuSerif fonts.

## Deploy workflow
- Develop on branch `claude/migrate-github-io-dev-domain-kw4o17`.
- Per change: commit → push → open a **draft** PR → mark ready → squash-merge
  into `main` → resync the branch to `origin/main` with `--force-with-lease`.
